║                          RELATIONSHIP TYPES                                ║
╚════════════════════════════════════════════════════════════════════════════╝

│  One-to-Many (1:∞)
│  ├─ USER → C2S_GROUP (one user leads many groups)
│  ├─ USER → MENTEE (one mentor has many mentees)
│  ├─ C2S_GROUP → MENTEE (one group has many members)
│  ├─ CLUSTER → BARANGAY (one cluster covers many barangays)
│  ├─ BARANGAY → SUBDIVISION (one barangay has many subdivisions)
│  ├─ MODULE → LESSON (one module has many lessons)
│  └─ LESSON → MENTEE_PROGRESS (one lesson tracked many times)
│
│  Many-to-Many (∞:∞)
│  ├─ C2S_GROUP ↔ GROUP_TAG (via GROUP_TAG_MAPPING)
│  └─ MENTEE ↔ TRAINING (via MENTEE_TRAINING)
│
│  Foreign Key References
│  ├─ C2S_GROUP.leader_id → USER.id
│  ├─ C2S_GROUP.cluster_id → CLUSTER.id
│  ├─ MENTEE.mentor_id → USER.id
│  ├─ MENTEE.assigned_group_id → C2S_GROUP.id
│  ├─ POTENTIAL_MENTEE.assigned_coordinator_id → USER.id
│  ├─ CLUSTER.cluster_head_id → USER.id
│  ├─ BARANGAY.cluster_id → CLUSTER.id
│  ├─ SUBDIVISION.barangay_id → BARANGAY.id
│  ├─ LESSON.module_id → MODULE.id
│  └─ MENTEE_PROGRESS.mentee_id → MENTEE.id


╔════════════════════════════════════════════════════════════════════════════╗
║                    KEY BUSINESS RULES & WORKFLOWS                          ║
╚════════════════════════════════════════════════════════════════════════════╝

1. ONBOARDING FLOW:
   Potential Mentee → Coordinator Review → Mentor Assignment → Active Mentee

2. PROGRESS TRACKING:
   Mentee → Module → Lessons → Progress Records → Completion

3. GROUP CAPACITY:
   C2S_GROUP.members_count <= C2S_GROUP.capacity
   Status: Open | Full | Closed

4. ROLE-BASED ACCESS:
   • Ministry Head: Full system access
   • Cluster Head: View cluster groups & mentors
   • Coordinator: Manage potential mentees, assign to mentors
   • Mentor: Manage own group & mentees

5. GEOGRAPHIC HIERARCHY:
   Cluster → Barangay → Subdivision → C2S Groups

6. ENDORSEMENT PIPELINE:
   Active Mentee → (Qualified) → Endorsed Worker → Lead Endorsed Group
